Early Access

LetsMeetVerse is still being built, one release at a time. While it's in Early Access, a code lets you in.

  • Windows app: an installer or a portable zip, for a town of your own that plays offline.
  • Linux build (beta), the same desktop app.

Already have an account? You don't need a code: sign in at play.letsmeetverse.com.
