Windows app

No installer: unzip the folder anywhere and double-click LetsMeetVerse.exe. Plays offline, saves on your PC.

Download for Windows

First launch: if Windows shows “Windows protected your PC”, choose More info → Run anyway. Needs the WebView2 runtime (built into Windows 11 and updated Windows 10).
